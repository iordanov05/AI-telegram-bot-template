# AI-Telegram-Bot-Template 🤖🧠

Шаблон Telegram-бота на **aiogram 3** с интеграцией AI через [OpenRouter](https://openrouter.ai/) — платформу для удобного подключения огромного количества различных LLM (бесплатных и платных).

---

## 📌 Описание

Готовый каркас для разработки Telegram-ботов на Python:  
✅ Подключение к OpenRouter для генерации AI-ответов  
✅ Чистая архитектура на aiogram 3  
✅ Поддержка истории сообщений  
✅ Централизованное логирование  
✅ Гибкая настройка через .env


---

## 🚀 Быстрый старт

1️⃣ Установи зависимости:

`make install`


2️⃣ Скопируй `.env.example` в `.env` и заполни свои ключи.


3️⃣ Запусти бота:

`make run`


---

## 🐳 Docker

`make docker-build`
`make docker-run`

## 🛠️ Makefile


Набор удобных команд для разработки и запуска проекта:

- `make install` — установка основных зависимостей
- `make lint` — проверка кода с помощью ruff
- `make format` — автоматическое форматирование кода
- `make typecheck` — проверка типов с помощью mypy
- `make test` — запуск тестов
- `make run` — запуск бота локально
- `make docker-build` — сборка Docker-образа
- `make docker-run` — запуск контейнера с ботом
